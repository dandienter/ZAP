⚠️ The Cheating Trap: Tantangan EdTech Berbasis Kunci Jawaban

Sebagian besar aplikasi pembelajaran saat ini (Photomath, Qanda, ChatGPT) beroperasi sebagai "Answer Engines" (Mesin Kunci Jawaban). Ketika siswa buntu, mereka memfoto soal dan aplikasi menyodorkan solusi instan. Hal ini memicu Cognitive Bypassing—proses berpikir kritis siswa dilewati secara instan, memicu ilusi pemahaman semu (illusion of explanatory depth).

Padahal, siswa kerap gagal di matematika bukan karena malas menghitung, melainkan karena memiliki cacat model mental (*conceptual misconception*) yang tidak pernah didiagnosis.

📝 Artefak Kognitif yang Terbuang

Kertas Buram (Scratchpad) adalah jejak berpikir siswa yang paling autentik: terdapat coretan ragu, asumsi awal, dan penurunan rumus. Namun karena guru kelas kewalahan memeriksa puluhan lembar kertas buram tiap jam pelajaran, kertas buram selalu berakhir di tempat sampah.

💡 Solusi: Socratic Cognitive Debugger

NalarAI adalah debugger kognitif yang memprioritaskan proses belajar dengan MENOLAK memberikan kunci jawaban. Siswa memfoto kertas buram mereka, AI melacak kontinuitas logika aljabar langkah demi langkah, dan menyajikan pertanyaan refleksi Sokrates agar siswa menemukan sendiri kesesatannya (*Aha! moment*).

Landasan Psikologi Kognitif & Pedagogis

Piaget: Disequilibrium

Belajar sejati terjadi saat asumsi siswa dibantah oleh kontradiksi nyata.

4 Tahap Pembedahan Kertas Buram

4 Sokrates & Kontra

AI menyajikan simulasi angka kontras tanpa membocorkan kunci jawaban.

Studi Kasus: Menyederhanakan Ekspansi Kuadrat

Contoh Kasus Eksekusi
TRANSKRIP CORETAN TANGAN SISWA: 
Baris 1:  (x + 3)^2 - 4     [BENTUK AWAL]
Baris 2:  x^2 + 9 - 4       [⚠️ TITIK PATAH LOGIKA]
Baris 3:  x^2 + 5           [HASIL KELIRU]
❌ Cacat Logika: Suku perkalian silang 2 · x · 3 = 6x terlewat!
EVALUASI DETERMINISTIK SYMPY: 
E_1 = (x + 3)**2 - 4
E_2 = x**2 + 9 - 4
Delta = simplify(E_2 - E_1)
Delta == -6*x  # (BUKAN 0! Invarian Patah di Baris 2)
✅ Breakpoint terisolasi secara matematis pada Baris 2.
Output Socratic Console (Zero-Answer Compliance):

"Di baris ke-2, kamu mengekspansi (x+3)² menjadi x² + 9. Coba uji dengan angka nyata: Jika x = 2, berapakah nilai dari (2 + 3)²? Lalu berapa hasil dari 2² + 9? Mengapa hasilnya menghasilkan 25 ≠ 13? Di manakah letak perbedaan nilai tersebut?"

The "Aha!" Moment Guarantee:

Ketika siswa melihat perbandingan angka 25 tidak sama dengan 13, otak mereka mengalami disequilibrium. Mereka membuka kembali bentuk kuadrat (x+3)(x+3) dan menyadari suku perkalian silang yang tertinggal. Kunci jawaban tidak pernah dibocorkan oleh sistem.

8/8 Pytest Verified (1.52s)

Cognitive Fault Localization (CFL)

Pola 1: Ekspansi Ilusi Distributif

Menganggap (a+b)² = a² + b² pada aljabar polinomial.

Pola 2: Persamaan Inversi Tanda Ruas

2x + 3 = 7 menjadi 2x = 10 (salah operasi pindah ruas).

Pola 3: Solusi Root Loss

x² = 4 menjadi x = 2 (kehilangan akar negatif).

ALGORITMA CFL: PERSAMAAN VS EKSPRESI backend/cfl/cfl_engine.py 
def steps_equivalent(prev, nxt, var: sp.Symbol = sp.Symbol('x')) -> bool | None:
    # Kasus 1: Persamaan Aljabar (Uji Ekuivalensi Himpunan Solusi)
    if isinstance(prev, sp.Eq) and isinstance(nxt, sp.Eq):
        s1 = sp.solveset(prev.lhs - prev.rhs, var, domain=sp.S.Reals)
        s2 = sp.solveset(nxt.lhs - nxt.rhs, var, domain=sp.S.Reals)
        if isinstance(s1, sp.ConditionSet) or isinstance(s2, sp.ConditionSet):
            return None  # Undecidable, jangan paksa vonis
        return s1 == s2

    # Kasus 2: Ekspresi Aljabar (Ekspansi/Penyederhanaan)
    if not isinstance(prev, sp.Eq) and not isinstance(nxt, sp.Eq):
        return sp.simplify(nxt - prev) == 0

    return False
ROBUST ZERO-ANSWER GUARDRAIL FILTER backend/cfl/guardrail.py 
class RobustZeroAnswerGuardrail:
    DECLARATIVE_PATTERNS = [
        r"(?:jawaban(?:\s*akhir)?|solusi|hasil\s+akhir)\s*(?:adalah|=|:)\s*(?:[a-zA-Z]\s*=\s*)?[-+−]?\s*(?:\d+(?:\/\d+)?|\d*\.?\d+|√\d+)",
        r"(?:maka|jadi|kesimpulannya),?\s+[a-zA-Z]\s*=\s*[-+−]?\s*(?:\d+(?:\/\d+)?|\d*\.?\d+|√\d+)"
    ]
    @classmethod
    def sanitize(cls, text: str, final_solution: str = None) -> str:
        for p in cls.DECLARATIVE_PATTERNS:
            text = re.sub(p, "Bagaimanakah menurut analisismu?", text, flags=re.IGNORECASE)
        return text  # Tidak pernah menyensor substitusi seperti 'Jika x = 2'
